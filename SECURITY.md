# Security Policy

## Supported versions

Security fixes are maintained for the following code:

| Version | Supported |
| --- | --- |
| Current `main` branch | Yes |
| Most recent published release, when one exists | Yes |
| Older releases and revisions | No |

Source metadata does not by itself establish that a release has been published. Check the
repository's releases before relying on release support.

## Report a vulnerability

Use the repository's
[private reporting form](https://github.com/ashtonchew/modal-computer-use/security/advisories/new).
Include the affected revision or version, impact, and a minimal reproduction when it is safe to do
so.

If the private form is unavailable, open an issue that asks a maintainer to establish a private
channel. Do not include vulnerability details in that issue.

Do not open a public issue, discussion, or pull request for an undisclosed vulnerability. Do not
include credentials, bearer tokens, noVNC URLs, clipboard contents, typed text, screenshots,
recordings, artifact bytes, or other sensitive user data in a report.

This policy does not promise a response or remediation time. Maintainers will use the private
advisory to discuss validation, disclosure, and any required release.

For deployment threats and operational safeguards, see the
[runtime security guide](https://github.com/ashtonchew/modal-computer-use/blob/main/docs/security.md).
