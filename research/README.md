# Research

This directory contains dated, non-normative research notes. Use it for market analysis, competitor
analysis, and design inputs that do not define the product contract.

Use `docs/` for product guidance, API contracts, specifications, and accepted benchmark reports.
Use `benchmark-data/` for tracked benchmark artifacts. Use `benchmark-results/` for local raw
benchmark evidence.

Research can support a product decision. It does not replace a specification, an API contract, or
measured benchmark evidence.
