# Community Code of Conduct

## Our commitment

We want project spaces to be open, welcoming, and safe. We do not tolerate harassment or abuse.

## Expected behavior

- Be respectful and constructive.
- Discuss ideas and code without attacking people.
- Accept feedback with care.
- Respect different backgrounds, identities, experiences, and viewpoints.
- Protect private and sensitive information.

## Unacceptable behavior

Unacceptable behavior includes harassment, threats, discriminatory language, sexual attention,
deliberate intimidation, sustained disruption, and publication of private information without
permission.

## Scope

This code applies in repository spaces. It also applies when a person represents the project in a
public space.

## Reporting and enforcement

Report sensitive conduct concerns through the repository's
[private reporting form](https://github.com/ashtonchew/modal-computer-use/security/advisories/new).
Start the report title with `[Conduct]`. If the form is unavailable, open an issue that asks a
maintainer to establish a private channel. Do not include sensitive details in that issue.

You can also use GitHub's block and abuse-reporting tools for conduct on GitHub.

Maintainers will review reports in private. They may remove content, limit participation, issue a
warning, or ban a participant. Maintainers must avoid conflicts of interest when they review a
report.
